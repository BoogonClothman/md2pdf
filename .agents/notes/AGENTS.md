# AGENTS.md — Agent Notes

Agent Note 本质上是 agent 撰写的 RFC：持久的提案与决策记录，保留依据、替代方案、
影响与必需的验证。规则权威是 [Agent Note 规则](README.md)；仓库级的常设要求
（非平凡变更须留痕）见[根 AGENTS.md](../../AGENTS.md)。

**每新增一份 Note 都要做取代检查**：在活跃目录树里搜索覆盖同一决策或机制的旧记录，
确认完全或部分取代关系，被完全取代的 implemented 记录在同一 PR 中归档或按
[归档与删除](README.md#归档与删除)合并删除；部分取代的保留双方并互相链接。

[`archived/`](archived/AGENTS.md) 下的文件是冻结的历史快照：永不编辑，也不作为
当前权威。
