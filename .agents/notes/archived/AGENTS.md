# AGENTS.md — 已归档的 Agent Notes

`archived/{class}/` 下的 Agent Note 是冻结的历史快照，不是当前权威。永不编辑、
重新格式化、移动或删除；新的决策与事实请查阅活跃记录或当前文档。

归档变更只允许：移动完整的 Note 文件、在 `Status: implemented` 行下插入
`Archived: YYYY-MM-DD` 行、修复或删除入站链接。出站链接不检查也不修复。

当前门禁（`npm run verify:notes`）校验其目录结构、状态行与 `Archived:` 行；
内容哈希封存（dsh 的 manifest 方案）留待后续门禁调整时加入——在那之前，冻结
依赖本节约定与 review 把关。
