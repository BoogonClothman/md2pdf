# AGENTS.md — 已实施的 Agent Notes

这里存放已交付的决策记录。遵循[规则](../README.md)与[根指令](../../../AGENTS.md)；
`npm run verify:notes` 门禁校验其生命周期骨架。

## 与实际交付的内容保持同步

当代码移动文件、改名、更改键名/默认值/结构时，在**同一个变更**里就地更正 Note 中
的对应事实，不追加变更历史。更正的是事实，不是决策。

当一份已实施的记录不太可能再指导未来工作时，按
[归档与删除](../README.md#归档与删除)将其移入 `archived/`，而不是无限期维护。

### 这不是重写*决策*的许可

就地更新事实是必需的；推翻决策本身或其依据，需要新写一份 Note 并与旧记录互相链接。
