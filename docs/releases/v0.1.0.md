# md2pdf v0.1.0

首个正式版本 — 跨平台 **Markdown → PDF** 桌面应用（Windows / macOS / Linux）。

分栏编辑器 + 实时预览，PDF 导出走 Chromium `printToPDF()`，**所见即所得**：
预览里渲染成什么样，PDF 里就是什么样。

## 下载

| 平台 | 文件 | 说明 |
|---|---|---|
| **Windows** | `md2pdf-0.1.0-win-x64.exe` | NSIS 安装器（可选安装目录） |
| **Windows 便携版** | `md2pdf-0.1.0-win-x64-portable.zip` | 解压即用，免安装 |
| **macOS (Apple Silicon)** | `md2pdf-0.1.0-mac-arm64.dmg` | 未签名：首次打开需 **右键 → 打开** |
| **macOS (Intel)** | `md2pdf-0.1.0-mac-x64.dmg` | 同上 |
| **Linux** | `md2pdf-0.1.0-linux-x86_64.AppImage` | `chmod +x` 后运行；无 fuse 用 `--appimage-extract-and-run` |
| **Linux (deb)** | `md2pdf-0.1.0-linux-amd64.deb` | `sudo dpkg -i`（缺依赖时 `sudo apt-get install -f`） |

完整性校验见 `SHA256SUMS.txt`。

## 功能

- 实时预览：GFM 表格 / 任务列表 / 代码高亮（highlight.js）
- **KaTeX 公式**（行内 `$...$`、块级与行内 `$$...$$`）
- **Mermaid 图表**（流程图、时序图…）
- PDF 导出：A4/Letter/Legal、横竖页、0–50mm 边距、页码、**书签大纲**
- 会话记忆：草稿 / 上次文件 / 导出设置跨启动恢复（localStorage）
- 浅色 UI；拖拽打开；未保存关闭三态对话框
- 快捷键：`Ctrl+O` 打开 · `Ctrl+S` 保存 · `Ctrl+E` 导出

## 构建与验证

- GitHub Actions 三端构建全绿（ubuntu / windows / macos）
- 每端 11 项自动化验证：PDF 魔数与内容、窗口截图、**上标几何断言**、
  退出路径（含脏关闭回归）、安全守卫（导航/弹窗拦截）
- 运行库全部 esbuild 打包，asar 内不含 node_modules

## 安全说明

- 不监听任何端口（`file://` 直载），CSP `connect-src 'none'`
- `will-navigate` 仅允许应用自身资源；弹窗拒绝；外链 scheme 白名单交系统浏览器
- `contextIsolation` + `sandbox` + `nodeIntegration: false`

## 已知限制

- macOS 构建**未签名未公证**（首次启动需右键 → 打开，或 `xattr -dr com.apple.quarantine /Applications/md2pdf.app`）
- `.npmrc` 镜像键在 npm 13 前产生警告（已知技术债，见 README）
